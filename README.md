# Jetpack Joe: Gold Rush

a retro style 2D arcade game made in Unity.

## Description

Jetpack Joe : Gold Rush is a 2D endless survival game where you play as a miner with a jetpack trying to survive inside a dangerous cave. The player has to control the miner using his jetpack and avoid the spikes that appear throughout the game. The longer you survive, the higher your score gets.

There are gold chunks which spawn in random locations through the game,which grant you extra points once collected. The game will begin from a main menu, where you can choose to start the game.
